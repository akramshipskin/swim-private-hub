# Font Swim Private Hub

Semua font gratis dari Google Fonts (lisensi SIL Open Font License, boleh dipakai komersial).

| Peran | Font | Bobot | Link |
|---|---|---|---|
| Judul & logotype | Sora | 600, 700, 800 | https://fonts.google.com/specimen/Sora |
| Teks isi & UI | Plus Jakarta Sans | 400, 500, 600, 700 | https://fonts.google.com/specimen/Plus+Jakarta+Sans |
| Angka/kode (opsional) | JetBrains Mono | 500, 600 | https://fonts.google.com/specimen/JetBrains+Mono |

Install font di komputer sebelum membuka file SVG lockup, supaya tulisan "swim.privatehub" tampil dengan Sora (kalau tidak ada, jatuh ke Arial).

File `sora-latin-variable.woff2` (Sora, huruf latin, bobot 100–800) disimpan di sini agar skrip `scripts/render-brand-social.mjs` bisa merender gambar tanpa unduh apa pun. Lisensi Sora: SIL Open Font License 1.1 (boleh dipakai dan disebarkan, termasuk komersial; teks lisensi lengkap di halaman Sora di Google Fonts).
